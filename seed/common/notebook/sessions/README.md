# Agent sessions

artifacts adjacent. A resumed session keeps its original folder and is linked from each active day's daily note.
These records preserve outcomes and reasoning, not transcripts. Use [the session template](../templates/session.md)
and the kit's [workflow](../../.scions/notebook-conventions/docs/workflow.md#sessions-and-closure).
