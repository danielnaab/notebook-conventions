# Source captures

Requested inputs to durable synthesis: articles, exports, meeting notes, research, and referenced assets.
Preserve source text; explanations and corrections belong in the wiki or an annotation.

- Name captures `YYYY-MM-DD-descriptive-name.md` using the capture date.
- Add a `## Source` section identifying the URL, document, or path and the capture date.
- Capture only requested material that [boundaries](../../docs/boundaries.md) allow.
- Deleting a capture requires authorization.
